# Catriver Gmeng

## How do I install these formulae?

`brew install catriver/gmeng/<formula>`

Or `brew tap catriver/gmeng` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "catriver/gmeng"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
